# Presentation Video

**Skill para o Codex voltada à criação de apresentações em vídeo com auxílio de inteligência artificial.**

## 📖 Sobre o projeto

O **Presentation Video** é uma skill desenvolvida para integrar fluxos de criação de apresentações em vídeo ao ambiente do Codex.

O objetivo é fornecer instruções estruturadas que auxiliem o agente de IA a interpretar solicitações e conduzir tarefas relacionadas à produção de apresentações audiovisuais.

## 🚀 Objetivo

Simplificar e padronizar o processo de criação de apresentações em vídeo, permitindo que tarefas sejam conduzidas por meio de instruções em linguagem natural.

## 📋 Pré-requisitos

- Codex com suporte a skills personalizadas.
- Acesso aos arquivos deste repositório.
- Dependências adicionais, caso exigidas pelos scripts da skill.

*A lista definitiva de dependências e ferramentas será documentada após a análise dos arquivos do projeto.*

## 📦 Instalação

**1.** Faça o clone deste repositório ou baixe seu conteúdo.

**2.** Copie a pasta `presentation-video` para o diretório de skills do Codex.

No Windows:

`C:\Users\<USUARIO>\.codex\skills\presentation-video`

No Linux ou macOS:

`~/.codex/skills/presentation-video`

**3.** Confira se o arquivo `SKILL.md` está no diretório correto.

**4.** Inicie o Codex e utilize a skill conforme as instruções disponíveis.

## 💻 Utilização

Descreva ao Codex a apresentação em vídeo que deseja produzir.

Exemplo de solicitação:

> Crie uma apresentação em vídeo sobre inteligência artificial, com uma introdução, explicação dos principais conceitos e conclusão.

O comportamento exato, os formatos de saída e as etapas automatizadas dependem das instruções implementadas na skill.

## 🛠️ Personalização

A skill pode ser adaptada às necessidades de cada projeto por meio da edição de suas instruções e dos arquivos que compõem sua implementação.

Antes de realizar alterações, consulte o `SKILL.md` para compreender seu funcionamento.
